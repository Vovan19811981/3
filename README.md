# Проєкт IoT-системи: Розумна теплиця (200 м²)

## 1. Вступ
Цей документ описує архітектуру та проєктні рішення для автоматизованої системи керування кліматом та мікрокліматом у промисловій теплиці площею 200 м². Система розроблена з урахуванням вимог безперервного моніторингу, автономності при втраті зв'язку з хмарним сервером та високої надійності виконавчих механізмів.
